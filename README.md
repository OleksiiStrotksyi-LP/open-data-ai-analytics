# Лабораторна робота №1

## з предмету "Середовище та компоненти розробки у моделюванні та аналізі даних"

### Тема: Використання системи контролю версій Git

### Мета:
- Навчитися працювати з відкритими даними: завантажувати, перевіряти якість, досліджувати та візуалізувати їх.
- Опанувати роботу з Git: окрема feature-гілка для кожного модуля, злиття через Pull Request, розв'язання merge-конфліктів, тегування версій.
- Навчитися організовувати файлову структуру аналітичного проєкту (`src`, `data`, `notebooks`, `reports`).

**Проєкт:** аналіз забезпеченості закладів освіти Львівської області укриттями та доступом до інтернету в них.

## Джерело даних

Набір даних «Забезпеченість укриттями закладів освіти та наявність в них доступу до мережі інтернет»,
Департамент освіти і науки Львівської обласної державної адміністрації:
https://data.loda.gov.ua/dataset/5e122bf0-9932-4226-9fb8-ccf07876f221

Набір містить дані про 2057 закладів освіти з 73 територіальних громад.
Файл опубліковано в кодуванні Windows-1251 з роздільником `;`, скрипт завантаження перетворює його в UTF-8.

Дані взято з Місцевого порталу відкритих даних Львівщини, оскільки під час виконання роботи
портал data.gov.ua був недоступний через технічні роботи.

Основні поля набору:

| Поле | Опис |
| --- | --- |
| `Community` | Територіальна громада Львівської області |
| `School` | Назва закладу освіти |
| `TypeOfInstitution` | Тип закладу (ЗЗСО, заклад дошкільної освіти, заклад позашкільної освіти тощо) |
| `Ownership` | Форма власності (комунальна, приватна, державна) |
| `AvailabilityOfShelter` | Укриття: власне, орендоване або відсутнє |
| `InternetInShelter` | Доступ до інтернету в укритті |
| `SpeedOfTrafficInTheShelter` | Сумарна швидкість трафіку в укритті, Мбіт/с |
| `Wi-FiInShelter` | Наявність Wi-Fi в укритті |

## Питання та гіпотези для аналізу

1. **Тип закладу та інтернет в укритті.** Чи відрізняються школи, дошкільні та позашкільні заклади за доступом до інтернету в укритті та за типом укриття (власне чи орендоване)?
   *Гіпотеза:* у школах інтернет в укриттях є частіше, ніж у дошкільних і позашкільних закладах, бо без нього неможливо продовжувати уроки під час тривоги.
2. **Нерівність між громадами.** Наскільки відрізняється частка укриттів з доступом до інтернету в різних громадах?
   *Гіпотеза:* розрив між громадами значний, а Львівська громада як обласний центр має частку вищу за середню по області.
3. **Швидкість інтернету.** Чи залежить швидкість інтернету в укритті від форми власності закладу та наявності Wi-Fi?
   *Гіпотеза:* у приватних закладах і в укриттях з Wi-Fi середня швидкість вища, ніж у комунальних закладах і в укриттях без Wi-Fi.

## Середовище розробки

- **Редактор:** [Zed](https://zed.dev/). Папка проєкту відкрита в Zed: код редагується в ньому, а Git-команди та Python-скрипти запускаються у вбудованому терміналі Zed (PowerShell).
- **Python:** 3.11+ у віртуальному середовищі `venv`. Папка `.venv/` не зберігається в Git (див. `.gitignore`).
- **Git + GitHub:** кожен модуль розробляється в окремій гілці `feature/<назва>` і зливається в `main` через Pull Request.

Створення та активація віртуального середовища (Windows, PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Якщо PowerShell блокує активацію, один раз виконайте `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

## Запуск

Усі скрипти запускаються з кореня репозиторію при активованому `.venv`:

```powershell
python src/data_load.py
```

- `data_quality_analysis` — перевіряє якість даних, уніфікує категорії та зберігає очищений набір у `data/processed/`.
